# Responsive Web Design with Bootstrap — Checkpoint Project

## 🎯 Objective
The goal of this project is to **create fully responsive web pages** using **Bootstrap 5** and its **grid system**.  
You will demonstrate your ability to use Bootstrap components, utilities, and layout techniques to design attractive, functional, and responsive interfaces.

---

## 🍽️ Part 1: Maridadi Bistro — Restaurant Website

### 📘 Project Overview
Design a fictional restaurant website named **Maridadi Bistro** using Bootstrap’s grid system and responsive classes.

### ✅ Requirements

#### 1. Header Section
- Include a **navigation bar** with:
  - Restaurant name/logo on the **left**.
  - Navigation links (**Home, Menu, About Us, Contact**) on the **right**.

#### 2. Hero Section
- Add a **hero image** background showcasing a delicious dish.
- Center a **heading**, a short **description**, and a **call-to-action button**.

#### 3. Menu Section
- Use the **Bootstrap grid system** to display menu items in a grid.
- Each card should include:
  - Image of the dish  
  - Title  
  - Short description  
  - Price  

#### 4. About Us Section
- Create a **two-column layout**:
  - Left column: image of the restaurant or chef  
  - Right column: a paragraph about the restaurant’s story  

#### 5. Contact Section
- Add a **contact form** with:
  - Name  
  - Email  
  - Message  
  - Submit button  

#### 6. Footer
- Include a **simple footer** with:
  - Copyright  
  - Social media icons (e.g., Facebook, Instagram, Twitter)

## ✈️ Part 2: Bonfire Adventures — Travel Agency Landing Page

### 📘 Project Overview
Build a **travel agency landing page** named **Bonfire Adventures** using **Bootstrap components** such as cards, accordions, buttons, and forms.

### ✅ Requirements

#### 1. Navbar
- Navigation bar with:
  - Agency name/logo on the **left**.
  - Navigation links (**Home, Destinations, Tours, Contact**) on the **right**.

#### 2. Hero Section
- Background image showing a beautiful travel destination.
- Include:
  - Heading  
  - Subheading  
  - Prominent call-to-action button (e.g., “Start Your Journey”)  

#### 3. Destinations Section
- Display **at least three travel destinations** using **Bootstrap cards**.
- Each card includes:
  - Image  
  - Title  
  - Description  
  - “Learn More” button  

#### 4. Tours Section
- Use **Bootstrap Accordion** to show different **tour packages**.
- Each item contains:
  - Tour title  
  - Brief details  
  - “View Details” link  

#### 5. Contact Section
- Add a **contact form** with:
  - Name  
  - Email  
  - Destination of interest (select input)  
  - Message field  

#### 6. Footer
- Include a **footer** with:
  - Copyright  
  - Social media icons

Both projects include **media queries** to ensure the layout adjusts for:
- Large screens (desktops/laptops)
- Tablets
